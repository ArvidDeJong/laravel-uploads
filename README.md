# darvis/laravel-uploads

[![Latest Version](https://img.shields.io/packagist/v/darvis/laravel-uploads.svg)](https://packagist.org/packages/darvis/laravel-uploads)
[![Tests](https://github.com/ArvidDeJong/laravel-uploads/actions/workflows/tests.yml/badge.svg)](https://github.com/ArvidDeJong/laravel-uploads/actions/workflows/tests.yml)
[![PHP](https://img.shields.io/packagist/dependency-v/darvis/laravel-uploads/php.svg)](https://packagist.org/packages/darvis/laravel-uploads)
[![License](https://img.shields.io/packagist/l/darvis/laravel-uploads.svg)](LICENSE)

One place for every file people upload to your Laravel application. A file becomes
an `Upload` row that knows which model it belongs to, which collection it is in,
whether it is public or private, who uploaded it and whatever extra data you keep
with it. From that row the package makes the thumbnails you configured, renders a
PDF to an image per page, hands out permanent or signed URLs, and removes the files
when the upload is deleted for good.

A light alternative to a full media library: one table, one model, one trait, one
action, and an optional pair of Livewire components for the upload form and the
administration.

![How darvis/laravel-uploads handles a file: addUpload stores it on the public or private disk with a row in the uploads table, a queued job makes the conversions and PDF pages, and the page shows a permanent URL or a signed link](https://arviddejong.github.io/laravel-uploads/assets/upload-flow.svg)

## Features

- **One model**: `Upload` with a polymorphic owner, `collection`, `disk`, `path`, `name`, `mime_type`, `size`, `is_public`, `sort_order`, `meta`, `conversions` and `processed_at`
- **`HasUploads` trait**: `$product->addUpload($file, 'photos', public: true)`, `uploadsIn('photos')`, `firstUpload()`, `reorderUploads()`
- **Public or private per upload**: a permanent URL for public files, a signed link that expires for private files, with a policy you can replace
- **Conversions from config**: named sizes in `jpg`, `png` or `webp`, `cover` or `contain`, generated by a queued job next to the original on the same disk
- **PDF pages**: a PDF is rendered to one image per page (Imagick or `pdftoppm`) and gets a thumbnail from its first page
- **Extra data** in a `meta` JSON column: `meta('caption')`, `setMeta('print.layer_height', 0.2)`
- **Soft and hard delete**: `delete()` keeps the files for a restore, `forceDelete()` removes everything, `uploads:prune` empties the trash after a number of days
- **Administration**: `UploadStatistics` with totals per disk and collection, and a Livewire overview with filters and the trash
- **Livewire upload manager**: upload, caption, drag to sort and remove for one collection of one model, with direct uploads to S3 when Livewire is set up for it
- **Dutch translation** of the components

## Requirements

- PHP 8.2 or higher with the GD extension
- Laravel 11, 12 or 13
- Livewire 3.6+ or 4 for the two components (optional)
- Imagick with Ghostscript, or the `pdftoppm` binary, for PDF pages (optional)

## Installation

```bash
composer require darvis/laravel-uploads
php artisan migrate
php artisan storage:link
```

[Installation & configuration](https://arviddejong.github.io/laravel-uploads/installation.html)
has the steps up to a first upload with thumbnails, the publish tags and every config key.

**New to Laravel?** The [tutorial](https://arviddejong.github.io/laravel-uploads/tutorial.html)
takes you from a fresh Laravel app to a page where you upload product photos and see their
thumbnails, and explains every step on the way.

## Quick start

```php
use Darvis\Uploads\Models\Concerns\HasUploads;

class Product extends Model
{
    use HasUploads;
}
```

```php
$photo = $product->addUpload($request->file('photo'), 'photos', public: true, meta: ['caption' => 'Front']);
$print = $product->addUpload($request->file('print'), 'files', meta: ['layer_height' => 0.2]);

$photo->thumbnailUrl();          // the thumb conversion, or the original until the job ran
$photo->conversionUrl('preview');
$print->downloadUrl();           // signed link, 30 minutes, checked by UploadPolicy
$print->humanSize();             // "1.2 MB"

$product->uploadsIn('photos')->get(); // ordered, without the trash
$product->firstUpload('photos');
```

```blade
<livewire:uploads.upload-manager :model="$product" collection="photos" :public="true" accept="jpg,jpeg,png,webp" />
<livewire:uploads.uploads-overview />
```

Conversions are defined once in `config/uploads.php`; `thumb` (300×300, cover, webp)
and `preview` (1200, contain, webp) ship by default. A PDF gets one image per page
plus the same conversions from its first page.

## Laravel Boost

The package ships [Laravel Boost](https://laravel.com/docs/boost) resources: a guideline
and a `laravel-uploads-development` skill. Run `php artisan boost:install`, or
`php artisan boost:update --discover` in a project that already uses Boost.
